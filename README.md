# Proyecto_PetCare
Proyecto de desarrollo de aplicaion para la materia analisis y diseño de sistemas, su finalidad es construoir una aplicaciòn para usuarios dueños de mascotas

# 🐾 Proyecto Pet-Care — Prototipo Web MVP

Prototipo funcional de la plataforma **Pet-Care**, maquetado en **HTML5** y **CSS3** a partir del diseño de alta fidelidad en Figma. Incluye los flujos de autenticación, gestión de mascotas, búsqueda de veterinarias, tienda de alimentos, servicio de transporte, calendario de recordatorios y pantallas de confirmación de estado.

---

## 🚀 Guía de Ejecución en Visual Studio Code

### 1. Clonar el repositorio

1. Abre **Visual Studio Code**.
2. En la pantalla de bienvenida o en el panel izquierdo de **Control de código fuente** (`Ctrl + Shift + G`), haz clic en **Clonar repositorio** (*Clone Repository*).
* *Alternativa desde la terminal de VS Code (`Ctrl + ñ`):*
```bash
git clone <URL_DE_TU_REPOSITORIO_PROYECTO_PETCARE>

```

3. Selecciona una carpeta en tu equipo para guardar el proyecto y haz clic en **Abrir** cuando VS Code lo solicite.

### 2. Ubicar la carpeta `pet-care-web`

1. Abre el **Explorador de archivos** en el panel lateral izquierdo (`Ctrl + Shift + E`).
2. Despliega la carpeta **`pet-care-web`** para visualizar los archivos `.html` y las subcarpetas `css/` e `img/`.

### 3. Abrir `index.html` en el navegador

1. Haz clic derecho sobre el archivo **`index.html`**.
2. Selecciona **Open in Default Browser** (si usas la extensión *Open in Browser*) o **Open with Live Server** (si usas *Live Server*).
3. El prototipo se abrirá automáticamente en tu navegador web predeterminado, permitiéndote recorrer todas las pantallas mediante los botones de cada interfaz o la barra superior de navegación rápida.
